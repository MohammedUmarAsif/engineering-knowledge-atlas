# Pathway 02: Full-Stack Product Engineer

Backend is part of this pathway, not a separate curriculum.

## Progression

Browser/runtime → UI architecture → accessibility → API contracts → service design → identity → relational data → caching and queues → testing → cloud delivery → observability → security → distributed failure.

## Senior emphasis

Architecture boundaries, data ownership, safe migrations, backward compatibility, operability, cost, incident learning, and simplification.
