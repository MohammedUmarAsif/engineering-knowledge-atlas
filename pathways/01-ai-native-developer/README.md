# Pathway 01: AI-Native Developer

## Outcome

Design, explain, evaluate, secure, and operate AI-enabled products rather than merely calling a model API.

## Progression

1. [AI foundations](../../knowledge/ai-engineering/01-foundations/README.md)
2. [Model application engineering](../../knowledge/ai-engineering/02-model-application-engineering/README.md)
3. [Document intelligence and retrieval](../../knowledge/ai-engineering/03-document-intelligence-retrieval/README.md)
4. [RAG architecture and evaluation](../../knowledge/ai-engineering/04-rag-systems-evaluation/README.md)
5. [Agents, workflows, and MCP](../../knowledge/ai-engineering/05-agents-workflows-mcp/README.md)

## Current module sequence

After passing AI foundations, complete model application engineering in this order:

1. API architecture and model selection
2. Instructions and context construction
3. Structured outputs and validation
4. Tool calling and side effects
5. Streaming, state, and memory
6. Multimodal applications
7. Reliability, security, and operations
8. Mastery review

## Exit standard

You can receive an ambiguous AI product request, clarify requirements, design the conventional and model components, define evaluations, identify risks, estimate latency and cost, describe observability, and plan failure handling.
