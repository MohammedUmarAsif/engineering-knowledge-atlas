# Pathway 04: Game AI and PhD Research

## Progression

Search → adversarial search → MCTS → planning → behavior and utility systems → reinforcement learning → multi-agent systems → imperfect information → player modelling → procedural content generation → believable agents → experimental design → publication.

## Research readiness

The pathway includes literature search, critical paper reading, hypothesis formulation, experimental design, statistical analysis, reproducibility, technical writing, and mapping potential Japanese laboratories.
