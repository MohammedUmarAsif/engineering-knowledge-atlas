# Pathway 03: Game Development, Design, and Narrative

## Streams

- Game engineering: loops, ECS, rendering, physics, animation, audio, networking, tools, performance.
- Game design: mechanics, dynamics, progression, balance, levels, economies, player psychology, accessibility.
- Narrative: worldbuilding, characters, dialogue, quests, branching state, environmental and emergent storytelling.
- Production: prototypes, vertical slices, pipelines, QA, localization, publishing, live operations.

Engine-specific information belongs beneath durable concepts, with Unity, Unreal, and Godot compared rather than treated as the curriculum.
