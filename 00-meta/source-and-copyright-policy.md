# Source and Copyright Policy

## Source rules

- Important claims should trace to a primary or authoritative source.
- Fast-moving pages require a `last_reviewed` field.
- Preprints must be labelled as preprints.
- Tool documentation must not be mistaken for independent evidence.
- A paper's conclusion must be separated from this repository's interpretation.
- GitHub star counts must be dated and must not be presented as evidence of correctness, security, or fit.
- Current tool recommendations require a maintenance and license check.
- “Latest” claims require a date, version, or publication reference.

## Document rules

A document may be committed only when redistribution is explicitly permitted. Public accessibility does not itself grant redistribution rights.

Each library item requires:

- title and author;
- canonical source URL;
- document type and publication date;
- license and redistribution status;
- local file path, when included;
- checksum for a local file;
- related topics;
- note location;
- date checked.

Copyrighted books remain external references. Personal notes about them may be committed.
