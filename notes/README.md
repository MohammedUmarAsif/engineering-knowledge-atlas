# Notes

Write notes in your own words. Use one of:

- `concept-notes/` for durable explanations;
- `reading-notes/` for books and documentation;
- `paper-notes/` for research;
- `comparisons/` for trade-off analysis;
- `questions/` for unresolved questions.

Do not copy long passages. Link to the source and distinguish the author's claim from your interpretation.
