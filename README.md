# Engineering Knowledge Atlas

A source-backed reading system for becoming an AI-native full-stack developer, developing senior engineering judgment, and building long-term expertise in game development, Game AI research, and Japanese.

This is not a collection to finish. It is a map for deciding what to understand next.

## Begin

1. Open [START-HERE.md](START-HERE.md).
2. Read [CURRENT-FOCUS.md](CURRENT-FOCUS.md) for the October AI interview priority.
3. Start [AI-Native Foundations](knowledge/ai-engineering/01-foundations/README.md).
4. Use the diagnostic at the top of every module. Skip only when you can answer it aloud without notes.

For a searchable local website, run `python3 scripts/docs.py serve` and open `http://127.0.0.1:8000`. See the [VS Code reading setup](00-meta/vscode-reading-setup.md) for the recommended layout.

## Repository model

- **Pathways** provide an ordered playlist.
- **Knowledge** contains canonical explanations.
- **Lenses** turn knowledge into senior-level judgment.
- **Library** records books, papers, specifications, and documentation with licenses.
- **Notes** contains your own durable understanding.

## Quality promise

Every maintained module must state prerequisites, diagnostic questions, learning outcomes, core explanations, failure modes, production implications, interview questions, primary sources, and a review date. Fast-moving material must distinguish stable principles from current tools.
