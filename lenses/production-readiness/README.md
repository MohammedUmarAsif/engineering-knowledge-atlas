# Production Readiness Lens

For each system, document:

- correctness and invariants;
- authentication, authorization, privacy, and abuse;
- latency and throughput targets;
- dependencies and failure isolation;
- retries, timeouts, idempotency, and backpressure;
- deployment, migration, and rollback;
- metrics, logs, traces, alerts, and runbooks;
- capacity and cost;
- data retention and deletion;
- graceful degradation and disaster recovery.
